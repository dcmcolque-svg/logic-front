# Build & Serve

## Serve locally (development)

```bash
ng serve
```

## Build for production

```bash
ng build --configuration=production
```

## Available configurations

| Config | API URL |
|--------|---------|
| `development` | `http://localhost:8082/` |
| `production` | `https://apilogic.nuvex.uk/` |
